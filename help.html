HELP CENTER

Get started in seconds.

Select a tool, drop your file into the browser, choose any options, and download. Files are never sent to a document-processing server.

Command shortcuts

Press Ctrl + K or ⌘ K to open the tool launcher. Use ↑ ↓ and Enter to select a tool, or Esc to close it.

Getting the PDF engines ready offline

GitHub Pages deployments from this repository's supplied GitHub Actions workflow bundle the PDF libraries at publish time. Once the app shell and vendor libraries have been cached by your browser, the supported PDF tools work offline. OCR needs extra Tesseract worker, core and language data which may be cached only when first used.

When running the ZIP locally in VS Code, the library files are not bundled yet. Connect to the internet for the first use, or run the optional scripts/setup-offline.ps1 on Windows before starting Live Server.

Why isn't my PDF smaller?

Compression rebuilds scanned pages as images. If a file already uses efficient text/vector content, the result may be larger, and searchability may be lost. The size limit input is a best-effort target, not a guarantee.

Can I use Nepali?

Switch the UI to नेपाली in the navigation. Generated Devanagari text is visually rendered by your browser's available font. Such generated pages are image based and not text-searchable. Nepali OCR is available when its language pack is installed.

Can I protect PDF files?

Protect PDF file creates a local authenticated encrypted .spdf container; it is not a standard PDF password. You can open it here with the correct password to restore the original PDF. The standard encrypted-PDF unlock workflow also requires you to know the password, and its output may be flattened.

What if the original PDF is corrupted?

Some PDFs can be opened in the reader and recovered as page images. Seriously damaged or password-protected files may fail; errors are shown rather than hiding the failure.

Other limitations

Existing PDF text editing is visual replacement, not native structure editing. Complex Word/Excel/PowerPoint conversion cannot reproduce exact positioning, tables or fonts. OCR may be imperfect. For secure redaction or legally binding signing use specialised software.
