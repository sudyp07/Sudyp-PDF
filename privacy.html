PRIVACY BY DESIGN

Your files stay on your device.

🔒 0 document bytes uploaded

Document file data is handled in your browser. There is no document upload endpoint, remote database or file processing backend.

What leaves your browser?

Before the vendor PDF libraries are installed, your browser may request the library JavaScript code from jsDelivr, Cloudflare CDN, or the OCR language servers. These parties can see ordinary network metadata such as IP address, but your PDF contents are not included. For GitHub Pages deployment, the supplied GitHub Actions workflow bundles the PDF engines into the hosted static site.

What is saved locally?

Tool IDs in favourites/recent lists, current UI language and an anonymous local count of successful processing jobs/files. Flashcards you type can be saved in localStorage by choice. Your actual PDFs, file names, passwords and file contents are never stored in localStorage.

Security

The .spdf encryption tool uses PBKDF2 with AES-GCM to protect data at rest. It does not produce standard password-protected PDFs; the correct password is needed to restore the original. Security checks and metadata clearing are not full forensic sanitisation.

Analytics

External analytics are off by default. A repository owner can choose to enable GoatCounter page-view analytics in the site configuration. If enabled, this produces external page-view requests but never uploads document data.

Clear the data

Use Clear workspace to release selected files from the current page; closing the tab also releases temporary file references. To remove saved favourites, recent IDs, counters and flashcards, clear this site's browser storage using browser settings.
